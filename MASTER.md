# The Masterwork Vault — Design System

## Visual thesis
A balanced 50/50 Menzoberranzan-and-modern interface: obsidian/basalt surfaces with restrained Faerzress violet and antique-gold accents; a fantasy serif used only for identity and section moments paired with a highly legible system sans-serif for data; an 8px-based compact-but-breathable spacing rhythm; softly rounded, bordered panels with shallow elevation rather than ornate fantasy frames.

## Interaction thesis
Fast, controlled motion using 140–220ms micro-interactions and 280–420ms panel transitions; hover uses a 2px lift, sharper border and restrained violet edge-light; view changes use 12px fade/translate entrances; atmospheric Three.js motion is isolated to the hero; no scroll-jacking, elastic bounce, giant zooms, persistent glowing data panels, or motion that delays crafting information.

## Tokens
- Obsidian: `#0B0A0F`
- Basalt: `#14121B`
- Panel: `#1B1725`
- Primary text: `#F3EFE6`
- Secondary text: `#B9B1C0`
- Faerzress violet: `#9A6CFF`
- Violet highlight: `#CBB6FF`
- Antique gold: `#D0AD5E`
- Base spacing: 8px; half-step: 4px
- Radii: 8 / 12 / 16 / 22px
- Motion: 140ms / 220ms / 360ms
- Signature easing: `cubic-bezier(0.2, 0, 0, 1)`

## Source/content policy
The app treats raw-material requirements as crafting cost. Commission, proficiency and focus are intentionally excluded. Source precedence is latest user correction > final organized ZIP screenshot > spreadsheet supplemental data. Spreadsheet item images are used only where the ZIP lacks a clean item crop.
